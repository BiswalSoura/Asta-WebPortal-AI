# Login Page

Users access WebPortal by entering their assigned username and password on the Login page. After successful authentication, the user is taken into the WebPortal application.

# Project List

The Project List page displays projects available to the logged-in user. Users can search available projects and review project information and status.

# Create New Project

The Create New Project page allows a user to begin a new project. The user enters the Project or Owner Title and completes the required project information before submitting the project.

# Building Address

On the Create New Project page, the building location can be entered using an address determined by the Google Maps API. Other available location methods may include Override Full Address or an APN / Parcel Number based location.

# APN Parcel Number

The APN / Parcel Number option can be used as a project location method when the applicable parcel information is available.
